# Лицензии данных и моделей: что можно в платном пилоте

Госзаказчик и грантодатель спросят одно: на чём обучена система и можно
ли её продавать. Здесь — ответ по каждому источнику. Сверено 27 сентября
2026 года; то, что не проверено по первоисточнику, помечено **проверить**.

## Можно использовать коммерчески

| Источник | Что берём | Лицензия |
|---|---|---|
| Sentinel-2, Sentinel-1 (Copernicus) | ряды снимков для поиска, радар | открытые данные Copernicus, коммерческое использование разрешено |
| Landsat 8/9 (USGS) | тепловой канал | общественное достояние |
| OpenStreetMap | контекстный отсев, дороги, реестр | ODbL 1.0: указывать авторство, производные базы — на тех же условиях |
| Дроновый набор свалок (INS, Waste-Dumpsites-DroneImagery) | обучение модели снимка | CC-BY-4.0: указывать авторство |
| DINOv2 (Meta) | признаки снимка | Apache 2.0 — **проверить** версию весов при выпуске |
| Карта зданий Microsoft Global ML Building Footprints | опыт 1к, в продукте не используется | ODbL — **проверить** |
| Карта земного покрова Impact Observatory | экзамен поиска (1н) | CC BY 4.0 — **проверить** |

## Нельзя использовать коммерчески без разрешения

| Источник | Где было | Что сделано |
|---|---|---|
| **AerialWaste** (Politecnico di Milano) | модель оценки снимка на карточках (`highres_score`, `aerialwaste_chip.joblib`), опыты DINOv2 | лицензия **CC BY-NC-ND 4.0** — только некоммерческое использование, без производных работ; сам набор включает снимки Google Earth, для которых действуют условия Google. В документах проекта раньше ошибочно стояло «CC BY» — исправлено. **Модель подсказки порядка переобучена без AerialWaste** (`dinov2_chip_open.joblib`) и стала лучше: 0,79 против 0,70 внутри северного кольца (AI_RESULTS.md, 1п) |

**Сделано 27 сентября:** оценку «Модель по снимку» на карточках объектов
теперь считает модель без AerialWaste (`dinov2_chip_open.joblib`). Старая
модель осталась в репозитории только для сравнения (`--model
models/aerialwaste_chip.joblib`) и в продукте не используется.

Модели, обученные на AerialWaste (`aerialwaste_chip`, `combined_chip`,
`dinov2_chip` и опытные `dinov2_chip_own*`, `dinov2_chip_b`), 27 сентября
убраны из репозитория и внесены в `.gitignore`: лицензия ND запрещает
распространять производные работы. Они остаются только на машине
разработчика для сравнения. **Проверить:** в истории коммитов они
остались; перед публичным запуском либо переписать историю, либо
согласовать с авторами AerialWaste.

## Снимки высокого разрешения — проверить условия

| Источник | Где используется | Что проверить |
|---|---|---|
| Esri World Imagery, Esri Wayback | подложка карты, паспорта, просмотр, модель снимка | условия использования Esri: показ с указанием авторства допускается, а коммерческое использование и обучение моделей на тайлах — **проверить** и при необходимости оформить учётную запись или лицензию |
| Bing Maps | доверификация снимков | условия Microsoft Bing Maps — **проверить** |
| Казахстанский набор (data/kz_dataset) | обучение модели снимка | разметка из OSM (ODbL), снимки — тайлы поставщиков выше, те же вопросы |

## Сервисы

| Сервис | Условия |
|---|---|
| Gemini API, бесплатный ключ | Google может использовать запросы для улучшения своих моделей: не отправлять закрытые данные заказчика. Платный тариф — другие условия |
| Planetary Computer (Microsoft) | каталог и доступ к открытым данным; лицензия — у каждого набора своя |
