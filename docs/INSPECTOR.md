# Инструкция инспектора: от очереди до акта

Одна страница для сотрудника, который работает с Vantage AI на пилоте.
Никакой установки не нужно — всё открывается в браузере.

## 1. Открыть очередь

Карта: https://hakathon-lyart.vercel.app/map.html

- Слева — **список объектов**, отсортированный по деньгам: сверху те, на
  которых больше всего ущерба.
- Справа — **«С чего начать»**: первые объекты, которые закрывают половину
  суммы очереди. Начинать с них.
- Метка **«нужен выезд»** — по снимку не разобрать, что там. Туда едут
  выяснить, а не составлять акт.
- Под списком «С чего начать» — ссылки **«Скачать очередь»**:
  GPX для навигатора в телефоне, Excel, паспорта объектов в PDF.

## 2. Подготовиться к выезду

1. Скачать **паспорта объектов** (PDF) и **GPX** — точки откроются в
   навигаторе (Organic Maps, OsmAnd, Google Maps через KML).
2. В камере телефона **включить геометку и дату**. Без координат в кадре
   выезд не засчитается — программа проверяет, что снимок сделан у объекта.
3. Объекты рядом объезжать за одну поездку: в паспорте указаны
   координаты, у соседних объектов они совпадают до третьего знака.

## 3. На месте — четыре кадра

1. **Общий план** — видны границы кучи и что вокруг.
2. **Вблизи** — из чего она: бытовой мусор, строительный, грунт.
3. **Подъезд** — колеи, съезд с дороги: возят ли сюда до сих пор.
4. **Экран телефона с координатами** рядом с кучей.

И решить: **свалка / не свалка / не понятно**.

## 4. Записать выезд

Кадры скопировать с телефона **файлами** — не пересылать через
мессенджер: он вырезает координаты. Затем одна команда:

```
python scripts/add_field_visit.py C00082 --verdict свалка ^
    --by "Фамилия И. О., должность" --photos D:/DCIM/*.jpg ^
    --note "бытовой мусор, свежие колеи"
```

Программа сразу проверит каждый кадр: есть ли координаты, не дальше ли
150 м от объекта, не позже ли даты выезда. Если ни один кадр не годится,
**выезд не запишется**, и программа скажет почему — это видно ещё рядом с
объектом, пока можно переснять.

После записи:

```
python scripts/attach_ground.py
python scripts/publish_filter.py
```

На карте у объекта появится метка **«выезд»**, а в карточке — кто и
когда подтвердил.

## 5. Акт

В карточке объекта — кнопка **«Черновик акта»**. Документ выходит
черновиком и становится актом только после подписи уполномоченного лица
с именем и должностью. К акту прикладываются кадры выезда.

## 6. Через месяц — контроль

Система сама перепроверяет объекты по снимкам: убран объект или засыпан
грунтом. Засыпанный помечается красным — туда стоит съездить ещё раз.

---

**Если что-то не так:** объекта нет на карте, координаты не совпадают,
выезд не записывается — напишите команде: [контакт]. Сообщение
«программа ошиблась» полезнее молчаливого обхода.
