# Vantage AI

**Обнаружение несанкционированных свалок по спутниковым данным, оценка ущерба в тенге и прогноз появления новых.**

Future Minds Hackathon 2026 · трек EcoFin · Астана

---

## Что делает система

Официальные реестры знают о десятках полигонов. Спутник видит объекты, которых в реестрах нет. Vantage AI находит их автоматически по всей области, датирует момент возникновения, оценивает ущерб бюджету с честным доверительным интервалом, готовит черновик акта для акимата, проверяет, что объект действительно убрали, и предсказывает, где свалка появится в следующие 12 месяцев.

```
Sentinel-2 · Sentinel-1 · Landsat 8/9
        │
        ├─ 3 оптических признака   NDVI · BSI · PMLI
        ├─ 1 радарный признак      нестабильность поверхности
        └─ 1 тепловой признак      аномалия температуры
        │
        ▼  необратимый разрыв во временном ряду за 8 лет
        ▼  контекстный отсев по OSM            тысячи → десятки
        ▼  сиамская сеть на парах «до / после»
        ▼  доверификация тайлами 0.7 м
        │
        ├─→ ущерб P10–P90 · метан в CO₂e · штраф по КоАП
        ├─→ черновик акта → подтверждение человеком → PDF
        ├─→ контроль устранения: убрали или засыпали
        ├─→ карта риска на 12 месяцев вперёд
        ├─→ Telegram-бот: оповещения службе + сообщения жителей
        └─→ карта, работающая без интернета
```

## Почему это не «нейросеть посмотрела на картинку»

Пять физических признаков находят место, где поверхность изменилась
**необратимо**. Опознаёт свалку не они, а контекстный отсев и человек —
это измерено, см. ниже. Каждый признак по отдельности неспецифичен:

| Признак | Физика | Что отсекает |
|---|---|---|
| Падение NDVI без восстановления | растительность гибнет и не возвращается | пашню **в обороте** — у неё NDVI возвращается каждую весну |
| Рост BSI | доля открытого грунта растёт | плотную застройку |
| Отклик PMLI в SWIR | обертоны C–H полимеров около 1730 и 2100–2300 нм | чистый грунт |
| Падение радарной стабильности | поверхность меняется от прохода к проходу | **карьер** — его стенки стабильны неделями |
| Тепловая аномалия | анаэробное разложение органики греет тело свалки | **снегосвалку** — она холоднее фона |

Модель не выдаёт вердикт. Она выдаёт **доказательную цепочку** с весом каждого признака.

**Чего эти признаки не делают — измерено.** Отличить свалку от склада
внутри одной местности они не могут: на подтверждённых объектах против
находок, оказавшихся ложными, ROC-AUC **0,500** — случайность. Зато
промышленную местность от сельской отличают уверенно (0,93).

Различают дальше две вещи, и обе не спектральные: контекстный отсев по
OpenStreetMap (385 кандидатов → 21) и человек со снимком 0,5 м на
пиксель. Так система и устроена.

Тест `test_optical_signals_alone_cannot_separate_them` прямо доказывает необходимость радара и тепла: без них карьер и свалка неразличимы.

### Где эти пять признаков не работают — измерено

Пашню в обороте они отсекают. Пашню, **выведенную из оборота**, — нет:
посевы прекратились и не вернулись, разрыв необратим, поведение как у
свалки.

Проверено трижды: Алматы — 8 находок, восточный пояс Астаны — 33,
юго-восточный — 63. **Сто четыре находки в сельской местности и ни одной
настоящей свалки.** Сила признаков у алматинской пашни оказалась **0,575**
против медианы **0,505** у подтверждённых свалок Астаны — то есть у поля
признаки были даже сильнее.

Разбор: [docs/BELTS.md](docs/BELTS.md) и [docs/ALMATY.md](docs/ALMATY.md).

Отсюда граница применимости, и она названа прямо: метод рассчитан на
ландшафт, где необратимое исчезновение растительности — редкое событие.
Степь, промзона, пригород. Там, где сельское хозяйство создаёт такой же
след законно, находки будут ложными.

Проверить область можно **до** прогона, за секунды и без единого снимка:
`scripts/probe_city.py` считает три показателя — долю земли, проходящей
отсев, долю промышленной земли и **полноту карты**, размеченные контуры
OpenStreetMap на квадратный километр.

Третий оказался самым сильным, и не случайно: он мерит ровно то, что
делает различение. Пять признаков находят необратимое изменение
поверхности, но свалку от склада внутри одной местности они не отличают —
ROC-AUC 0,500, ровно случайность. Отсеивает лишнее контекстный фильтр по
OSM, и работает он настолько, насколько подробна карта.

| Область | Контуров/км² | Промышленной | Настоящих свалок |
|---|---:|---:|---|
| **север Астаны** | **94,7** | 3,02% | 3 подтверждённых + 5 опознанных |
| юго-восточный пояс | 18,1 | 0,06% | 0 из 9 просмотренных |
| восточный пояс | **6,8** | 0,00% | 0 из 33 |

Порядок совпал с числом найденных свалок целиком, разрыв — **в
четырнадцать раз**. Восточный пояс замер теперь помечает как «НЕ
ЗАПУСКАТЬ» — до четырёх часов счёта, а не после.

Раз замер стоит секунды, область перестала выбираться догадкой:
`scripts/scan_density.py` промеряет сетку клеток вокруг города. Просмотр
всей агломерации Астаны — 35 клеток — занял двенадцать минут и нашёл
непроверенную область плотнее работающей (150,4 против 94,7). Три
пригородных пояса до этого выбирались догадкой, стоили четырнадцать часов
счёта и дали ноль настоящих свалок.

## Установка

Требуется **Python 3.10+**.

```powershell
git clone https://github.com/k41270075-stack/hakathon.git
cd hakathon

python -m venv .venv
.venv\Scripts\activate

# Windows: путь может содержать нелатинские символы,
# setuptools без этого падает при editable-установке
$env:PYTHONUTF8 = "1"

pip install -e ".[dev]"       # гео-пайплайн и тесты
pip install -e ".[ml]"        # PyTorch, LightGBM
pip install -e ".[service]"   # FastAPI, бот, генерация актов
```

Linux / macOS: `source .venv/bin/activate`, переменная `PYTHONUTF8` не нужна.

**Если путь к проекту содержит казахские буквы** (`Жұмыс үстелі`), это
ломает не установку, а чтение снимков, и ломает молча. `pyogrio` при
импорте отдаёт GDAL путь к сертификатам внутри проекта; `ұ`, `ү`, `і` не
представимы в кодовой странице Windows, и schannel отбрасывает файл
сертификатов целиком — ни один COG по HTTPS не открывается. Ошибку при
этом не видно: rasterio пытается прочитать сообщение GDAL как UTF-8 и
падает с `UnicodeDecodeError`, потеряв текст.

Лечится само: [`vantage/env.py`](src/vantage/env.py) кладёт копию
сертификатов по ASCII-пути и выставляет переменные **до** первого
гео-импорта. Отдельно делать ничего не нужно, но знать об этом стоит:
симптом выглядит как «сеть не работает», а сеть работает.

## Быстрый старт

```powershell
vantage info                          # область, период, пороги
vantage doctor                        # готовность к сдаче
vantage scenes --collection s2        # сколько снимков доступно
vantage money 5000 --sensitivity      # ущерб от объекта 5000 м²
```

Настоящий прогон. Область идёт плитками, каждая пишет результат на диск и
при повторе берётся из кеша — прерывание безопасно:

```powershell
# кольцо 20x20 км вокруг северной промзоны: там шесть полигонов ТБО в OSM
vantage run --bbox 71.37,51.12,71.66,51.30 --name astana_north

vantage web                           # лендинг и карта на http://127.0.0.1:8080
```

Скорость измерена на настоящих данных: **около 6 секунд на км²** за восемь
лет (плитка 22 км² — примерно две с половиной минуты). Отсюда область из
конфигурации, 4834 км², — это порядка восьми часов; для первого прогона
берите `--bbox` поменьше.

Синтетика никуда не делась — она нужна, чтобы разрабатывать интерфейс, не
дожидаясь прогона:

```powershell
vantage sample                        # синтетика, помечена красной полосой
```

Сайт собирается Vite и состоит из пяти страниц. `vantage web` копирует
артефакты прогона, собирает и поднимает всё локально:

```powershell
vantage web                           # http://127.0.0.1:8080
vantage web --no-build                # без пересборки, если dist уже есть
```

Сборка самодостаточна: `web-next/dist` открывается и с локального сервера,
и с флешки, и без интернета. Шрифты лежат в репозитории, подложка карты по
умолчанию — координатная сетка, а не тайлы. Спутниковый снимок включается
кнопкой, когда сеть есть.

Сервис:

```powershell
$env:VANTAGE_API_TOKENS = "op-token-1234:operator,ak-token-1234:akimat"
python -m uvicorn "vantage.api:create_app" --factory --port 8000
# документация: http://127.0.0.1:8000/docs
```

Бот:

```powershell
$env:VANTAGE_BOT_TOKEN = "токен от @BotFather"
$env:VANTAGE_BOT_SALT = "случайная строка"
$env:VANTAGE_BOT_SUBSCRIBERS = "ваш chat_id"
python -m vantage.bot
```

## Принципы

1. **Ни одного магического числа в коде.** Любой порог живёт в YAML и имеет имя.
2. **У каждой цифры есть происхождение:** `source` (документ), `derived` (формула) или `estimate` (инженерная оценка). `vantage doctor` падает при `TODO`.
3. **Диапазоны вместо точечных цифр.** Ущерб публикуется как P10/P50/P90.
4. **Метры считаются в метрах.** Только в UTM, никогда в градусах.
5. **Каждый шаг — отдельная команда и отдельный артефакт на диске.**
6. **Модель предлагает, человек подтверждает.** Акт не выгружается как официальный без подтверждения именем и должностью.
7. **Житель видит зону, служба видит точку.** Публичный контур не отдаёт ни координат, ни идентификаторов.

## Честные ограничения

Их называют первыми, не дожидаясь вопроса:

- **Последние 18 месяцев система не подтверждает.** Признак свалки — необратимость: NDVI упал и не вернулся. Проверка смотрит в окно 18 месяцев после разрыва, и у объекта, возникшего позже, этого окна просто нет — «не восстановился» там означает «смотреть было не на что». Первый настоящий прогон это и показал: 25 из 29 кандидатов получили одну и ту же дату, последний месяц периода. Теперь такие разрывы отбрасываются на этапе поиска. Свежие объекты видит гражданский контур, а не спутник.
- **10 метров на пиксель.** Объекты меньше 30–50 м² Sentinel-2 не разрешает. Компенсируется гражданским контуром: житель видит то, чего не видит спутник.
- **Доверификация выборочная.** Тайлы высокого разрешения подтягиваются для лучших кандидатов, а не для всего массива.
- **Прокси когерентности, а не интерферометрия.** Строгая обработка фазы требует парных SLC-снимков.
- **Четыре параметра экономики — инженерная оценка**, а не документ. `vantage doctor` перечисляет их поимённо.
- **Перенос классификатора на Казахстан не доказан.** Модель обучена на AerialWaste (5 220 снимков, ROC-AUC 0,858 на их данных); на наших объектах 0,643 при интервале по бутстрэпу 0,333–0,923 — нижняя граница ниже случайного. Виновата не модель, а размер проверки.
- **Метод не универсален по ландшафту.** Там, где сельское хозяйство даёт такой же след, что и свалка, находки будут ложными. Проверять область следует до прогона: `scripts/probe_city.py`.
- **Проверка идёт по снимкам, а не с земли.** Просмотр по 0,5 м/пиксель отличает свалку от склада, но не заменяет выезд. Источник проверки хранится по каждому объекту отдельным полем и на сайте не смешивается.
- **Это модель вероятности, а не юридическое доказательство.** Решение о статусе объекта, штрафе и факте устранения принимает уполномоченное лицо. Vantage AI ускоряет и удешевляет процесс, но не заменяет инспектора.

## Данные проверены

STAC по области Астаны вернул **2392 сцены Sentinel-2**, после фильтра по пригодным месяцам осталось **1574**, покрытие 2018–2026 равномерное.

Прогон по плитке 22 км² к юго-западу от города: 442 даты, 61 месячный
композит, 98,4% валидных пикселей после маски облаков. Он же выявил
ошибку, которую не показала бы никакая синтетика — см. «Честные
ограничения», пункт про последние 18 месяцев.

Источники экономических величин: МРП 2026 = 4325 ₸ (закон о бюджете), плотность ТБО 0,25 т/м³ (методика расчёта тарифа, ИПС «Әділет»), цены приёма вторсырья (прайс LS Ecolife, Астана), ст. 344 ч. 2-1 КоАП РК (100 МРП физлицу, 1000 МРП крупному бизнесу), цена углеродной единицы 400–560 ₸/т CO₂ (биржевые сделки РК), модель метана — IPCC 2006 Vol.5 Ch.3 + GWP по AR6.
