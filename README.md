# VANTAGE

**Обнаружение несанкционированных свалок по спутниковым данным, оценка ущерба в тенге и прогноз появления новых.**

Future Minds Hackathon 2026 · трек EcoFin · Астана

---

## Что делает система

Официальные реестры знают о десятках полигонов. Спутник видит сотни объектов, которых в реестрах нет. VANTAGE находит их автоматически по всей области, датирует момент возникновения, оценивает ущерб бюджету с честным доверительным интервалом, готовит черновик акта для акимата и предсказывает, где свалка появится в следующие 12 месяцев.

```
Sentinel-2 / Sentinel-1 / Landsat
        │
        ├─ маска облаков, месячные композиты за 8 лет
        ├─ 6 спектральных признаков (NDVI, BSI, PMLI, NDWI, NDMI, NBR)
        ├─ радарная стабильность поверхности (S1)
        └─ тепловая аномалия (Landsat TIRS)
        │
        ▼
  поиск необратимых разрывов во временном ряду (BFAST / CCDC)
        │
        ▼
  контекстный отсев: OSM, дороги, кольцо от жилья      →  тысячи → десятки
        │
        ▼
  сиамская сеть на парах «до / после» + панель объяснимости
        │
        ▼
  доверификация тайлами высокого разрешения (несколько провайдеров)
        │
        ├─→ денежный слой: ущерб, вторсырьё, метан, штраф (Монте-Карло)
        ├─→ черновик акта → подтверждение человеком → официальный PDF
        ├─→ Telegram-бот: оповещение + входящие сообщения жителей
        ├─→ контроль устранения по нескольким признакам
        └─→ модель риска: карта появления новых свалок на 12 месяцев
```

---

## Почему это не «нейросеть посмотрела на картинку»

Свалка опознаётся **пятью независимыми физическими признаками**, каждый из которых по отдельности неспецифичен:

| Признак | Физика | Что отсекает |
|---|---|---|
| Падение NDVI без восстановления | растительность гибнет и не возвращается | пашню — у неё NDVI возвращается каждую весну |
| Рост BSI | доля открытого грунта и минерального мусора | плотную застройку |
| Отклик PMLI в SWIR | обертоны C–H полимеров около 1730 и 2100–2300 нм попадают в B11/B12 | чистый грунт |
| Падение радарной когерентности S1 | поверхность постоянно меняется — техника, ветер, оседание | стабильную степь |
| Тепловая аномалия Landsat TIRS | анаэробное разложение органики греет тело свалки | карьеры и отвалы грунта |

Модель не выдаёт вердикт — она выдаёт **доказательную цепочку** с весом каждого признака (`vantage.explain`).

## Технологический стек

| Слой | Технологии |
|---|---|
| Данные | STAC (Planetary Computer), `pystac-client`, `odc-stac`, Cloud-Optimized GeoTIFF по HTTP-range |
| Обработка растров | `xarray`, `dask`, `rioxarray`, `rasterio` |
| Геометрия | `shapely`, `geopandas`, `pyproj` (все расчёты — в UTM 42N, не в градусах) |
| Детекция изменений | собственная реализация поиска разрывов временного ряда (CUSUM + сегментация) |
| Классификация | PyTorch, сиамская сеть, бэкбон предобучен на Sentinel-2 (`torchgeo`) |
| Прогноз риска | LightGBM по пространственным признакам сетки |
| Экономика | Монте-Карло по треугольным распределениям, модель метана IPCC FOD |
| Документы | ReportLab — черновик акта с обязательным подтверждением человеком |
| Сервис | FastAPI, ролевой доступ, публичная агрегированная выдача |
| Бот | `python-telegram-bot` — двусторонний: оповещения + приём сообщений жителей |
| Фронтенд | MapLibre GL, offline-first PWA (демо работает без интернета) |

## Установка

Требуется **Python 3.10+**.

```bash
git clone <repo-url>
cd vantage

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

# базовый гео-пайплайн
pip install -e ".[dev]"

# модели (PyTorch, LightGBM) — ставится отдельно, весит много
pip install -e ".[ml]"

# API, бот, генерация актов
pip install -e ".[service]"
```

## Быстрый старт

```bash
# 1. Что сконфигурировано: область, период, пороги
vantage info

# 2. Проверка готовности — в первую очередь честности экономических цифр
vantage doctor

# 3. Сколько снимков реально доступно по нашей области
vantage scenes --collection s2
vantage scenes --collection s1
vantage scenes --collection landsat
```

Область интереса, период и все пороги задаются в [`config/default.yaml`](config/default.yaml).
Экономические допущения — в [`config/economics_astana.yaml`](config/economics_astana.yaml).

## Структура репозитория

```
config/
  default.yaml             пороги, окна, границы — ни одного магического числа в коде
  economics_astana.yaml    тарифы и цены; у каждого числа есть min/typical/max и source
src/vantage/
  config.py                типизированная загрузка конфигурации
  aoi.py                   область интереса, проекции, нарезка на плитки
  catalog.py               поиск сцен в STAC
  indices.py               спектральные индексы — физическая основа детекции
  cli.py                   командный интерфейс
tests/                     юнит-тесты (физический смысл, а не «функция не упала»)
docs/                      архитектурные заметки и разбор модулей
```

## Принципы, которым следует код

1. **Ни одного магического числа в коде.** Любой порог живёт в YAML и имеет имя.
2. **Каждая экономическая цифра имеет источник.** `vantage doctor` падает, если остался хоть один `source: TODO`.
3. **Диапазоны вместо точечных цифр.** Ущерб считается методом Монте-Карло и публикуется как P10/P50/P90.
4. **Метры считаются в метрах.** Любое расстояние, площадь и буфер — только в проекции UTM, никогда в градусах.
5. **Каждый шаг пайплайна — отдельная команда и отдельный артефакт на диске.** Любой шаг перезапускается независимо.
6. **Модель предлагает, человек подтверждает.** Акт не может быть выгружен как официальный документ без явного подтверждения человеком.

## Честные ограничения

Их нужно называть первыми, а не ждать вопроса:

- **10 м на пиксель.** Объекты меньше ~30–50 м² Sentinel-2 не разрешает. Система ловит средние и крупные.
- **Доверификация — выборочная.** Тайлы высокого разрешения подтягиваются для лучших кандидатов, а не для всего массива.
- **Это модель вероятности, а не юридическое доказательство.** Финальное решение о статусе объекта, штрафе и факте устранения принимает человек. VANTAGE ускоряет и удешевляет процесс, но не заменяет инспектора.
